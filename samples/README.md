# 가상 서류 샘플 (samples)

기능을 시험하기 위해 **지어낸** 서류 세트입니다. 실제 서류가 아니며, 이름·번호·주소·금액은 모두 임의의 값입니다.
모든 쪽 위·아래에 "가상 서류" 띠가 들어 있습니다.

## 구성

- 사례 폴더 9개. 각 폴더에 `청구서.pdf`, `첨부자료.pdf`, `답변서.pdf`가 있습니다.
- `시험사례.json`: 사례별 입력값과 기대 결과. 나중에 만들 점검 규칙의 자동 시험이 읽습니다.
- `make-samples.mjs`: 위 파일을 다시 만드는 스크립트. 내용을 바꾸고 싶으면 이 파일의 사례 부분을 고친 뒤 다시 실행합니다.

## 기준 날짜

- 처분을 안 날: 2026-03-10 (화)
- 기한일(90일째): 2026-06-08 (월) — 민법 기간 계산(초일 불산입)으로 구한 값이며, 구현 전에 law.go.kr에서 조문을 확인합니다.

## 다시 만드는 방법

my-app 폴더에서 실행합니다. Windows의 Microsoft Edge 또는 Chrome이 필요합니다.

```bash
node samples/make-samples.mjs
```

## 아직 없는 것

- HWP, Word, JPG 형식의 샘플은 없습니다. (PDF만 있습니다.) 해당 형식의 읽기 시험이 필요한 작업 13·14번 전에 추가합니다.
